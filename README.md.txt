# Blinkit Dashboard 🚀
## Power BI Project for Sales & Outlet Analysis  

📊 This Power BI dashboard provides insights into Blinkit’s sales, outlet performance, and product trends.  

### 🔍 Key Insights  
✅ *Total Sales:* $1.20M  
✅ *Average Sales:* $141  
✅ *Total Items Sold:* 8,523  
✅ *Average Rating:* 3.9  

### 📊 Features  
- *Sales Breakdown* by product category  
- *Outlet Performance* (Size, Type, Location)  
- *Trend Analysis* of sales over time  
- *Product Insights* (Fat Content, Item Type)  

### 🛠 Tools Used  
- *Power BI, DAX, Excel/CSV*
